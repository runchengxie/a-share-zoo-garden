# 退市事件处理契约

动物园、植物园以及其他共享回测组件遇到退市成分时，统一记录以下字段：证券代码、退市日期、最后可观测交易日、是否存在可核实现金结算、采用的估值政策和成分移除日期。

## 严格口径

退市日没有行情且没有可核实现金结算事件时，停止跨越该日期的正式净值计算，并写出 `blocked` 证据。不得把缺失值静默记为零，也不得把最后价格伪装成现金到账。

## 研究代理口径

研究版可以使用退市前最后有效复权价格作为代理结算价，退市日收益记为零，随后移除成分并按剩余组合规则继续计算。输出必须同时标记：

- `delisting_policy=last_price_proxy`
- `evidence_tier=research_proxy`
- 退市审计文件及每个事件的 `strict_status=blocked`

研究代理序列不能替代严格口径，也不能解释为正式可交易业绩。网页、导出文件和回测报告都必须保留该标记。

## 发布门禁

动物园每日任务在生成数据后运行 `scripts/validate_published_evidence.py`。如果代理口径、元数据或退市审计表不一致，发布会停止。植物园没有退市代理事件时仍使用严格口径，但沿用同一字段命名，方便跨策略审计。
