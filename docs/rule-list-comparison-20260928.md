# 动物园词表历史口径对照

下列数值是退市整理期过滤和 2026-09-28 证券、更名快照发布前的归档结果。跨越 2026-06-26 的净值因旧退市持仓缺价而撤回，不再用于业绩展示或规则优劣结论。当前可运行的公共执行诊断见 [动物园公共执行模拟诊断](formal-execution-diagnostic.md)。

本次使用离线缓存回放三种规则口径。历史规则和首版冻结规则从第一版可核实生效日 2025-12-22 开始。当前词表回溯从缓存能完整支持的 2021-09-06 开始，属于事后分类实验。三组均使用同一历史简称、日行情、复权因子、停牌数据和沪深 300 ETF 基准。首日收盘作为建仓起点，以下是未扣额外交易费用的严格版和扩展版终值。

同起点的另一次独立回放把三组都设为 2025-12-22 建仓。当前词表严格版终值为 1.0914，扩展版为 0.9670。历史规则与首版冻结仍分别为 1.0218 和 0.9649。这一差值衡量在相同窗口里使用后来才确定的词表会如何改变结果，不能解释为已知规则的可执行超额收益。

历史规则和首版冻结在本次窗口里完全相同。缓存截至 2026-09-04，而下一版动物园规则生效日为 2026-09-07。因此这批数据尚不能检验后续新增词的贡献。2021-09-06 至 2025-12-21 只有当前词表的事后回溯，没有可核实的当时规则业绩。

运行入口是 `zoo-rule-comparison`，参数包括 `--rules`、`--cache-dir`、`--calendar-nav`、`--output-dir`、`--start-date` 和 `--end-date`。程序要求全量行情、复权、停牌和基准缓存，缺项即停止。每组独立输出 `nav.csv`，同时写出 `comparison.json` 和逐文件哈希清单。输出目录必须为空且位于仓库外，避免覆盖现有公开净值。全区间输入清单摘要为 `071adee99a1c955475b7df29536301eb9d6c5c8cc8ee314e355b99552d23b23c`，同起点清单摘要为 `1c412d0e6fc0b6b22f80deac9718d1fbe7290311754745079101eec4bf749fe1`。

这些仍是现有 Zoo 指数算法的对照，包含月初等权、缺行情重归一等原有约定。它们不是公共执行引擎的成交账本，也不能代替模拟盘或实盘证据。
