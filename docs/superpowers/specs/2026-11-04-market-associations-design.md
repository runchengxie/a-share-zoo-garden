# 市场联想观察池设计

用户已授权按对话中的三步方案推进。第一期交付观察池规则、羊字辈来源记录和独立中英双语页面。

## 方案选择

直接扩大指数词表会混淆字面分类与市场叙事。只写研究文档不便读者检索。因此采用独立、人工审核的观察池，通过现有 React 页面展示经过审查的公开 JSON，不接入指数计算。

## 数据与展示

记录稳定 ID、证券代码、报道中的名称、动物或植物主题、关联类型、对应词、来源、报道可知时间、项目收录时间、审核时间、状态、证据级别、复核期限和追加状态事件。状态支持待核实、已确认和已失效。已确认仅指来源明确建立联系，不确认上涨原因或投资资格。网友联想保持待核实。首批逐条收录所选报道中当日行情段落提及的全部标的，明确这是报道样本，不是全市场候选池。

页面提供主题和状态筛选，显示证据、时间、复核期限、来源链接及样本限制。没有植物案例时明确说明。文案纳入现有中英 locale catalogs。原文标题和证券名称保留来源语言。

## 时间与研究边界

项目收录时间使用实际审核时点，报道时间仅代表所核查来源的最早时间，不宣称全网首次。观测表现不得早于审核和公开发布两者较晚者后的首个交易日。本期不生成收益序列，公开发布时点尚未知。每条关联默认 30 个自然日复核，过期需复核不等于自动认定无效，失效与重启追加事件、保留原记录。未来独立设计前瞻行情跟踪。

## 验证

数据契约测试覆盖时间顺序、唯一 ID、来源引用、网友联想不确认、状态记录和无收益字段。浏览器验证双语、筛选、空状态、外链和手机布局。运行仓库要求的 Python 和前端门禁。
