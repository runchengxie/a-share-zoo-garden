# 指数方法

[English page](methodology.md)

动物园、植物园分别按历史证券简称和独立词表分类，共用行情、资格筛选、收益和状态管理代码。名称主题成员身份与指数可投资资格分开判断。

## 规则与历史可用性

`rules.yml`、`plant_rules.yml` 定义严格词表、扩展词表、`exclude_patterns`，以及只接受 ts_code 的 `force_include`、`force_exclude`。扩展匹配包含严格关键词。严格层侧重明确的现实生物名称，扩展层可包含高歧义词、集合概念或神话生物。公司行业相关但名称没有匹配词，不构成主题成员。

历史简称使用 `namechange` 的 as-of 记录，服务端按页获取并补充 2006 年缺失区间。未知历史简称不能用当前 `stock_basic.name` 回填。`list_date`、`delist_date` 筛选历史证券范围，ST、交易所、上市时长和流动性进一步限制资格。

| 配置键 | 含义 |
| --- | --- |
| `min_listing_days` | 上市自然日下限，0 表示关闭 |
| `min_daily_amount` | 再平衡日成交额下限，0 表示关闭 |
| `max_suspension_days` | 连续停牌交易日触发移除的阈值，0 表示关闭 |

规则通过 `effective_from` 和历史文件选择版本。2026-09-07 或 2026-09-25 新增的动物词不会进入更早篮子。最早已知动物词表日期是 2025-12-22，更早回放沿用该词表，属于事后假设。植物园保存 2026-09-05 词表，2026-09-25 新增词从生效日起使用。统一的 2021-01-04 图表起点不代表当时已有这些词表。

## 状态与收益

共同起点为 2021-01-04 收盘，净值设为 1。收盘后确定初始持仓，从下一交易日累计收益。每月首个交易日重算篮子，赋予等权固定权重，月内持有。再平衡当日收益由旧篮子产生，新权重次日生效。

股票、ETF 收益使用复权价格比率：

```text
(close_t * adj_t) / (last_traded_close * last_traded_adj) - 1
```

确认停牌时保留持仓和权重，当日收益为 0。复牌时计入从最近有效估值起的复权价格变化。其他缺行情情况保留原权重、收益贡献为 0，不重新分配权重。退市缺价另按下文严格与代理边界处理。无状态单日辅助函数有独立的缺价归一化口径，不与每日状态化指数混用。

指数收益是各持仓权重乘收益之和。复权因子近似分红再投的总收益，不是现金红利到账、税费或再投资交易会计。ETF 必须有 `fund_adj`，缺失时停止，不能按 1 替代。指数基准直接使用 `close / pre_close - 1`。不能在已复权的 ETF `pre_close` 上重复乘复权比率。

## 异常调样与退市

退市、公告可知且生效的退市整理期、新 ST 或达到配置的连续停牌天数可触发移除。当天仍用旧持仓，剩余篮子的新等权次日生效。只有日期的公告从下一日决策起可用；月度候选池也排除已知退市整理期证券。

CLI 默认 `--delisting-policy strict`。退市缺行情且没有已核实结算时，停止跨越该日期的计算。研究选项 `last_price_proxy` 使用最近有效复权估值作为代理，退市日收益为 0 并移除成分，metadata 标记 `evidence_tier=research_proxy`。这不是已核实现金结算。两类指数的实际定时策略见[架构与运维](architecture.zh-CN.md#部署)，契约和历史诊断见[退市事件契约](delisting-event-contract.md)及[正式诊断](formal-execution-diagnostic.md)。

## 可选交易成本层

`backtest.yml` 默认 `enabled: false`，`commission_rate`、`stamp_tax_rate`、`slippage_rate` 都为 0。开启后保留毛收益，并在 NAV 和公开快照追加换手、成本、净收益及净值字段。

`formal` extra 固定 `quant-backtest-runtime` v4 与 `quant-platform` 会计 provider，要求 Python 3.12 及以上，且必须配置仓库外的绝对 `ZOO_BACKTEST_RUNTIME_ROOT`，用于输入、作业数据库和输出。缺少配置时拒绝运行。严格版与扩展版分别提交再平衡结算。

比较新等权目标前，旧权重随价格漂移。换手为已执行权重变化绝对值之和的一半；佣金和滑点按已执行变化计算，印花税只计卖出。停牌证券无法成交，相关交易保持待处理。成本层本身不证明历史输入可用性或实际可交易性。

## 名称审核与证据

`zoo-audit` 分别展示主题成员身份和指数资格，可对确定性结果附加 Gemini、OpenRouter 建议。报告保存输入和规则哈希、provider、模型和 prompt 版本。模型一致意见只提高审核优先级，`confidence` 不是校准概率。规则须显式批准并记录生效日期，audit JSON 不直接成为指数规则。

历史[词表对照](rule-list-comparison-20260928.md)保留样本期间与已撤回业绩的限制。合成契约测试校验工程行为，不证明历史收益。本次文档审计没有运行真实数据回填或产生新的数值研究结论。
